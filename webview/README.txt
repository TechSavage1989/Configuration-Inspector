Config Inspector 5.13.0 - compact Windows x64 desktop edition

Run Config_Inspector_5.13.0.exe. No companion files or app installation are required. Microsoft Edge WebView2 Evergreen Runtime must already be installed. Runtime download: https://developer.microsoft.com/microsoft-edge/webview2/

This edition replaces the bundled Electron runtime with the installed WebView2 runtime. The complete HTML interface is embedded in the EXE and served from memory. Configuration processing remains local. It does not download the app or send configurations to a website.

App settings are available in the sidebar and native File menu. App data defaults to LocalAppData/ConfigInspectorWebView, outside the executable folder. Choose another location in App settings; it takes effect on the next launch. The embedded WebView2 loader is extracted to Host-5.13.0 under the chosen folder. The browser profile and window placement live under Profile and WindowPlacement.bin there. HKCU/Software/ConfigInspector retains only the folder choice and migration/cleanup instructions. An older registry window placement is migrated on save. Preferences from the Electron edition are not automatically migrated. Imported configuration files remain in their original locations.

Features: native open-file controls provided by WebView2, drag and drop, native Save dialog for exports, clipboard copy/paste, light/dark themes, zoom, F11 full screen, and window size/position retention. The WebView2 interface retains the established design and local configuration workflow. Built-in executable/taskbar icon is compiled into the PE resource, with no post-build icon modification.

Build on Linux using MinGW-w64 GCC: run sh build.sh. WebView2 SDK 1.0.2903.40 header and official x64 loader are included with Microsoft license and notice. EventToken.h and guids.h provide MinGW compatibility. No Electron, Node.js, .NET or VC++ redistributable is needed by the host executable; it imports Windows system DLLs and loads the embedded WebView2 loader.

Validation: Windows PE imports/resources inspected; embedded HTML and loader checked against source; HTML browser imports and exports tested. Native Windows launch, runtime integration and actual startup timing have not been tested in this Linux environment.
