# Config Inspector 5.38.1

## Vendor stencil pictures drawn correctly

- **Fix:** stencil pictures built from clipped pieces (the Aruba AP-515 and other HPE Aruba wireless shapes) were drawn as scattered fragments. The app now applies the picture's clipping paths, so the access point is drawn as it is in Visio, front and back.
- **Fix:** a closing command that Visio writes at the end of some pictures no longer paints a white box over the whole shape.
