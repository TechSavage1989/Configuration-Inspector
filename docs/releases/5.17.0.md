# Config Inspector 5.17.0

## Side-by-side comparison workspace

- Fix comparison contents being clipped instead of scrollable, including short windows.
- Add a dedicated **Config text / files** mode: left/right UTF-8 files or pasted
  text, aligned line numbers, added/removed/changed highlights, synchronized
  vertical/horizontal scrolling and Previous/Next difference navigation (F7 /
  Shift+F7). Direct text is read-only, stays local and is never written to files.
- Keep large comparisons responsive with 500 aligned rows per page, bounded diff
  work and a disclosed approximate alignment fallback. All accepted input remains
  available; oversized inputs are rejected explicitly rather than silently cut.
- Upgrade **Config objects** with paired left/right identities and property values,
  original-setting details, state/category/search filters and unchanged objects.
  Existing vendor/context/type/name matching remains conservative; ambiguous
  duplicates are not guessed and renames appear as additions/removals.
- Preserve the original-field table, source exports, secret masking and update
  safeguards. Secret-only object changes remain reported while values are masked.
- Preserve accepted text comparison inputs across the encrypted desktop updater
  handoff; pending input dialogs must be saved or canceled before restarting.

Direct text inputs are limited to 5 MB per side, require UTF-8 and an explicit
unmasked-display acknowledgment. Loaded configuration source follows masking;
masked text can hide secret-only differences. CRLF/LF are normalized for matching,
while final-newline differences remain visible. This is not an editor or merge tool.

Windows x64 / WebView2 and standalone HTML editions remain available under the
existing download names. Builds remain unsigned; existing SHA-256, size, identity,
architecture and version checks continue to protect the update transaction.
