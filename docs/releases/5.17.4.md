# Config Inspector 5.17.4

## Restore imported configuration selection

- **Use imported** is available on both the Current and Comparison sides in Config Objects, Config Text / Files and Original Fields.
- Choose configurations already open in the workspace without reopening or reparsing their files. The picker remains available when the input area is collapsed.
- Replacing one side preserves the other input, active mode, comparison filters and loader collapse state. Existing replace/paste, clear and Swap sides controls remain available.
- Imported source masking is preserved. The picker displays identity metadata only; parsed comparisons retain their same-vendor compatibility guard.

This corrects the missing selection route introduced by the newer comparison layout. Comparisons remain read-only; maps, navigation, scrolling, parsers and updater behavior are unchanged.
