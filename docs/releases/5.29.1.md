# Config Inspector 5.29.1

## Site map fits the window, and links are clickable

- The **Site map** page now fits the window: the map fills the remaining height, so the page itself no longer scrolls. Only the device panel beside it scrolls on its own.
- Click a line between two devices to see that connection in the side panel. It lists each link with the ports at both ends, plus link state, speed, description, MAC address and VLANs for each port where the imported data has them, and how the link was discovered. Below that are both devices with their model, address and buttons to select them or open their configuration. The selected link is highlighted on the map.
