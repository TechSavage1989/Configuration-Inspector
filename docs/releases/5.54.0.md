# Config Inspector 5.54.0

## Hardware packs shared with NetworkDiagramStudio

- **One format for both apps:** **Save hardware pack** (under **Stencils**) now writes NetworkDiagramStudio's hardware pack format. The same file opens in NetworkDiagramStudio, with each shape's picture, its ports by name and the models it fits. Config Inspector also keeps its Visio masters, port points and shape choices in the file, so nothing is lost when the pack comes back here.
- **NetworkDiagramStudio packs import here:** each shape's picture becomes a stencil shape, and its mapped ports place the links by port name. The shape is chosen for devices whose model it lists, and it is still exported to Visio as a master.
- Hardware packs saved by earlier versions of Config Inspector still import.
