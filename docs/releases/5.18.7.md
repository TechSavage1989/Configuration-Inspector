Automatic update checks now start immediately when the interface is ready, removing the previous 15-second startup delay. While the app stays open, checks run every two minutes instead of five. Re-enabling automatic checks also checks immediately. Network requests remain asynchronous, and disabled checks, release-specific Later reminders and retry backoff are preserved.

The updater has a new compact card in both themes, with clear version information, download size, percentage progress and distinct download, verification, ready and error states. Details opens immediately without an extra network request. Progress updates preserve keyboard focus and expanded release notes. Download verification, explicit restart confirmation and workspace recovery remain in place.
