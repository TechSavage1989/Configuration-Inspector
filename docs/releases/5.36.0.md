# Config Inspector 5.36.0

## No more freezes at launch or after loading files

- **Launch:** your stored vendor stencils now load in the background after the window opens, one file at a time. The app keeps each stencil in its already-read form, so later launches skip reading it again. The first launch after updating reads each stencil once more.
- **Loading configurations and monitoring data:** link-state lookups use an index, instead of scanning every imported interface for each port.
- **Stencil matching:** each device is compared only with shapes that share its model number, so libraries of thousands of shapes match quickly.

## Diagrams

- **Ports on stencils:** link lines meet the exact center of a port drawn by a vendor stencil.
- **Fewer bends:** links take routes with fewer bends and fewer short jogs.
- **Grouped access points:** with **Group into one box per switch**, the ports they use are outlined in the access point color on the switch.
- **Fix:** a vendor stencil's ports are mapped group by group only when they are exactly the device's ports; otherwise the earlier count-based mapping is used, so extra marks on a shape can no longer shift links to the wrong ports (an Aruba 6100 stencil drew port 41 on port 35).
- **Firewall port maps:** firewalls (and routers) get a port map page of their own, apart from the switches.
