# Config Inspector 5.54.3

## Network diagram

- **Checked against many network designs:** diagrams are now tested on many more kinds of network:
  - Cisco, Fortinet, SonicWall, Aruba, Juniper, MikroTik, Huawei, Palo Alto, Sophos and Meraki configurations
  - switch stacks and HA firewall pairs
  - up to four WAN circuits, and sites without a firewall
  - wide and deep switch trees, and rings
  - 25, 40 and 100 Gbps links
  - unknown hardware and unusual port names

  The checks cover routing, WAN placement, line hops, port modules and Visio exports. These fixes came from that testing:
- **Copper into a fiber cage:** a link from an RJ45 port into an SFP cage is shown as copper, with an RJ45 copper module in the cage, instead of as fiber.
- **AOC links:** active optical cables are their own link type (purple), with an AOC cable end in the ports.
- **Modules on any fiber port:** a fiber, DAC or AOC link on a port the hardware does not show as a cage (an add-in network module, or hardware without a known layout) still gets its module, drawn as a cage.
- Long module names wrap in the legend instead of running into the drawing.
