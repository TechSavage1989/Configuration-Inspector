# Config Inspector 5.34.1

## Stencils: devices and files on separate tabs

- The **Stencils** dialog now has two tabs, so a long list of imported files no longer pushes the devices out of reach:
  - **Devices**, shown first: each device and access point with its stencil choice.
  - **Stencil files**: the imported files, each with **Remove**.
- Each tab has its own search box: find a device by name or model, or a stencil file by name.
