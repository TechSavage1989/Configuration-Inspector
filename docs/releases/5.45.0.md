# Config Inspector 5.45.0

## More on one readable sheet

- **Port labels:** port names on links lie flat beside their line when neighboring ports leave room, so the band above and below each device shrinks from 72 to 36 px. Ports packed too closely keep rotated labels, in a band only as tall as the longest one.
- **Arrangement:** the diagram tries the three most promising row widths in full, routes included, and keeps the one that prints largest on the sheet. Before, it chose from estimates that left out the routes.
- **First page keeps every switch:** when a device-and-below diagram is too large to read on one sheet, its first page still shows every device below the selected one (access points summarized per switch, other endpoints kept). Each branch's detail continues on its own page. Before, the first page showed only one level, so selecting the firewall hid switches further down.

## Neighbors

- **Fix:** a neighbor that a monitoring export reports on the wrong local port (such as a FortiGate's unused "ha" port for a link that its "x3" port carries) now shows the correct port in the Neighbors tables, as the diagram already did, with "(reported ha)" beside it. The correction applies when the far end's description names this device and one of its ports, and the reported port is not up.
