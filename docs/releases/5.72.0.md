# Config Inspector 5.72.0

## Network diagram (preview)

The Network diagram is back as a preview you turn on yourself: **App settings > Preview features > Network diagram (preview)**. It then appears in the sidebar whenever configurations or monitoring exports are open.

- **Same engine as NetworkDiagramStudio:** the pages are drawn by NetworkDiagramStudio's own diagram engine, so both apps produce the same drawings from the same files: the network page with real faceplates and numbered ports, a site map, port maps, port inventory, wireless connections, and VLANs and routing.
- **Stays responsive:** the pages are drawn in the background; you can keep using the app while a large site is drawn.
- **Scope:** by default the pages show the devices you opened configurations for and the access points cabled to them. **Every other device** adds the rest of what a monitoring export lists.
- **Downloads:** **Visio** (all pages, editable), **This page (SVG)**, **Printable pages** (one HTML file to print or save as PDF), and **Edit in NetworkDiagramStudio**, a project file to open there when you want to move devices and cables by hand.

Limits of the preview: the pages cannot be edited inside Config Inspector yet, hand-made Site map changes are not applied to them, and a file format NetworkDiagramStudio does not read is listed under the import notes instead of being drawn. The earlier diagram tool stays switched off.
