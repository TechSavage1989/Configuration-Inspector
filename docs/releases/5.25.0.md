# Config Inspector 5.25.0

## Cleaner pages, with the facts an engineer needs up front

- **Device summary** at the top of the Overview: hostname, vendor and OS, model (for example "2 × WS-C3650-48PD (stack of 2)"), firmware, serial number, management address, default gateway, DNS, NTP, syslog, time zone and domain, with tiles for ports in use, VLANs, routes or firewall rules, and review findings.
- The Overview now shows the summary, the top review findings, interfaces at a glance and the policy summary. The duplicate network map, totals grid, DNS/gateway cards and parser notes were removed; they are still on their own pages.
- **Device information** starts with the same summary. Stack members with the same model are grouped into one specification panel. Original export fields and source file details are in collapsed sections.
- **Source on demand:** section pages no longer open with a source panel. Use **View source** on the file line to show the original lines, and **Hide source** to close them.
- **Easier tables:** long port lists show a count and ranges (for example `40  Gi1/0/1-20, Gi2/0/1-20`), with the full list on hover. The duplicate Member ports column on VLANs is gone, and a status column is hidden when every row just says "Configured".
- **Less repetition:** once a file is open, **Add files** and **Paste** sit next to the open files, and the extra header buttons are gone. Sidebar entries no longer repeat a single sub-item under themselves.
