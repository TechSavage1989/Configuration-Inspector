# Config Inspector 5.47.0

## Visio export

- **Fix:** Microsoft Visio still reported error 271 ("parts are missing or invalid") on exported drawings. Visio files are now written in the same plain package form as NetworkDiagramStudio's exports, which open in the same copy of Visio:
  - no document-property parts (title, author and organization stay on the drawing itself);
  - a minimal document part (settings, the fonts the shapes use, one default style and the document sheet);
  - rectangles drawn with absolute geometry rows tied to the shape size;
  - each page linked only to the stencil masters it uses.
