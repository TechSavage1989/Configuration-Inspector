# Config Inspector 5.21.0

## Client report

- **Convert & export → Client report** creates one printable document for every open configuration, ready for a client or a ticket.
- It starts with a cover summary (devices, ports in use, findings) and then gives each device its details, port usage (in use, configured but idle, disabled or unconfigured), logical interfaces, VLANs, IP addresses and review findings ordered by severity.
- Passwords, keys and other secrets are never included. Open the file and choose **Print or save as PDF**.

## Change summary

- In **Compare configs → Config objects**, **Change summary** lists what changed in plain language, grouped by category, for example `GigabitEthernet1/0/14: Untagged VLANs: 10 → 30` or `Tagged VLANs: removed 100`.
- Added and removed objects include their description or VLAN name, and possible renames are mentioned once.
- Copy the summary or download it as a text file. Sensitive values are always masked.
