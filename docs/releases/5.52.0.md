# Config Inspector 5.52.0

## Network diagram

- **Line hops:** where two links cross, one hops over the other in a small arc, as Visio draws line jumps. The Visio export keeps the same arcs, so the drawing looks the same in Visio. Crossings close together share one hop.
- **Links spread out:** links avoid running close beside each other or bunching on one side of a device. For example, a firewall's fiber uplink takes the side its WAN handoff leaves free.

## Link types

- **More cable types:** the cable type list now covers copper grades (Cat5 to Cat8, shielded, PoE), fiber by reach and grade (SR, SR4, LR, LR4, ER, ZR, BiDi, CWDM, DWDM, OM1 to OM5, OS1 and OS2), direct attach cables (SFP, SFP+, SFP28, SFP56, QSFP+, QSFP28, QSFP56, QSFP-DD and OSFP DACs, breakout and active DACs, twinax), AOCs, and other links: stacking, HA, console, serial, T1/E1, DSL, coax, wireless, cellular, satellite, MPLS and internet circuits. Any other type can still be typed in.
