# Config Inspector 5.29.0

## Search supplementary data

- The search box now also searches supplementary data: devices, live interfaces, neighbors, ARP entries, MAC address table entries, routes and networks. It matches names, IP addresses and MAC addresses in any notation (`00:00:5e:00:53:01`, `0000.5e00.5301`, `00-00-5e-00-53-01`).
- Results are organized by type. A row of tabs above the results (**All**, **Parsed objects**, **Original fields**, **Configuration text**, **Supplementary data** and others, each with a count) filters them, and supplementary matches are grouped under **Devices**, **Interfaces (live)**, **Neighbors and links**, **ARP entries**, **MAC address table**, **Routes (live)** and **Networks**.
- Each supplementary match has copyable values and actions: **Details**, **Show on site map**, **Open configuration** or **Open interface**.
- With only supplementary data open, the search box still works on it.

## Zoom and move the site map

- Scroll the mouse wheel over the **Site map** to zoom around the pointer, or use the **−**, **+**, **Fit** and **100%** buttons on the map. Drag the map to move it. A click without dragging still selects a device.
