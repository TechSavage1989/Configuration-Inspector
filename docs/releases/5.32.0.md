# Config Inspector 5.32.0

## Vendor stencils in network diagrams

- Import your vendor Visio stencils (.vssx), or a Visio drawing that already uses them (.vsdx), with **Stencils** on the Network diagram page or with **Add files**.
- **Matching:** devices use the vendor shape that matches their part number or model. On a device row you can pick another shape or a drawn faceplate.
- **Port placement:** when the stencil marks its ports (connection points) and they fit the device's ports, each link lands on its actual port on the vendor artwork. Otherwise links meet the device in port order.
- **Downloads:** Visio files contain the vendor shapes, so they open in Visio as the vendor's own masters. SVG and printable HTML show the artwork.
- **Storage:** stencils stay in the app on this computer and are never sent anywhere.

## Network diagram

- **Add or remove devices** lists every device of the site:
  - Untick a device to remove it, or right-click it on the diagram.
  - Tick a device from elsewhere to add it in its tier.
  - **Undo added and removed devices** restores the automatic selection.
- The drawing choice is now **Stencils where available**, **Drawn faceplates** or **Boxes**.

## Linked names and addresses

- Device names and addresses in tables, side panels and details are links:
  - **Configuration open:** the link opens that device's configuration, at the named interface when there is one. For example, the devices listed for a duplicate address in Site overview.
  - **Device known only from imported data:** the link opens its imported details.
- An address configured on more than one device is not linked.

## Fixes

- **Site map:** selecting a device with a long list of connections no longer shrinks the map and cuts off its bottom.
- **Neighbor ports:** when a monitoring export reports a link on a port that is down, the far end's configured description names another port, and that port is up, the site map and diagrams use the described port. For example, a firewall uplink reported on `ha` is shown on `x3`.
