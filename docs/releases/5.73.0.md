# Config Inspector 5.73.0

## Site map: one link per cable

- **Separate links for separate uplinks:** when two devices are joined by several cables that are not aggregated, each cable is now drawn as its own link, with its own port tag on each device (for example `port1` to `6` and `port2` to `41` side by side), instead of one line labelled with all the ports.
- **LAGs stay together:** cables whose ports belong to the same LAG, trunk group or port channel in an open configuration are still drawn as one thicker link whose tags list the member ports.
- Selecting any of the links between two devices lights up all of them and lists every cable in the panel, as before.
