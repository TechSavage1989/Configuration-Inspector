# Config Inspector 5.50.0

## Link types

- **Base colors:** the Link type dialog offers 48 base colors (reds, oranges, yellows, greens, teals, blues, purples, pinks, browns and grays in several shades) beside the color picker.
- **Speed and cable type:** each link type has a speed and a cable type, chosen from a list (10 Mbps to 400 Gbps; copper grades, SR/LR/ER, multimode and single-mode fiber, DAC, AOC, handoffs and more) or typed in. While the legend name has not been set by hand it follows them (for example "25 Gbps SR fiber"), and every link of the type shows its speed and cable type when you point at it. They can be changed at any time, for one link or the whole type.

## Diagram editing

- Holding **Shift** while dragging a device, access point, link end, corner or stretch keeps the move horizontal or vertical, whichever is larger.

## Pages

- The first page tab is called **Core network**.
- **Trunk VLANs** fit as many port columns on a page as stay readable (up to 11 instead of 7), and each page lists only the VLANs its columns carry.
- On wireless connections pages, access points grow (up to twice their size) to use the room their switch leaves, while each row still stays within the switch's width.

## Hardware

- About 200 more firewall and switch models have verified port layouts, adapted from NetworkDiagramStudio's hardware catalog with each manufacturer reference kept: among them SonicWall TZ270 to TZ670 and TZ600, FortiGate 40F, 70F, 80F, 200F and 400F, Cisco Catalyst 3560-E and 9300, Cisco ASA and Firepower, Netgate, OPNsense, Juniper SRX and EX, Palo Alto and many more HPE Aruba switches and modules. Hardware without a known layout still gets a plain faceplate built from its ports.
