# Config Inspector 5.24.0

## Migration validation no longer freezes the app

- **Migration validation** in Compare configs now opens in well under a second, even for large stacked switches. Before, matching on a large export could take many minutes and stop the app from responding.
- The page explains what it is for: put the **original** configuration on the left and the **new** device's configuration on the right, and every object from the original is checked against the new one.
- Results open on **Needs attention**, which lists only objects with different settings, objects missing on the new device, objects only on the new device, and objects that need a manual check. Filter buttons show the other groups, including **Same settings**.
- Results are shown 50 at a time. Open an item to see its settings side by side, with changed rows highlighted. Renamed objects can be matched manually from the item.
- Compare modes are now ordered **Config objects**, **Config text / files**, **Migration validation**, **Original fields**, with the same highlight for whichever mode is active.
