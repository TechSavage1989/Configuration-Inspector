# Config Inspector 5.19.0

## New configuration formats

- **Arista EOS** running configurations are recognized as Arista instead of Cisco. Interfaces, VLANs, Port-Channels, routes (including VRF routes), DNS, NTP, logging and users are shown, and the model and EOS version are read from the export header.
- **Huawei VRP** configurations (`display current-configuration` output or saved `.cfg` files) are recognized. The device name, VLANs (including `vlan batch` ranges), access, trunk and hybrid ports, Eth-Trunk aggregation, Vlanif addresses, static routes, DHCP relay, DNS, NTP, logging, SNMP, spanning tree and local users are shown. Other VRP commands stay available in the original source. A trunk without an exported allow-pass list is not assumed to carry every VLAN.
- Huawei encrypted values and shared keys are hidden when sensitive values are hidden. Shared-key lines are now hidden for every command-line vendor.

## Comparing configurations

- In **Config objects**, a removed object and an added object of the same type with identical settings apart from the name are labeled **Possible rename**, naming the other object. They still count as one removal and one addition; nothing is matched automatically.

## Updates

- Automatic update checks now run at startup and every six hours instead of every two minutes, so several copies on the same network no longer exhaust GitHub's request limit. **Help → Check for updates** still checks immediately.
- Unchanged releases are confirmed with a lightweight request. If GitHub limits requests, automatic checks wait for the time GitHub reports before trying again.

## Help

- The README has a new Troubleshooting section, and Help & format support describes the Arista EOS and Huawei VRP formats.
