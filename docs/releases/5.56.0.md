# Config Inspector 5.56.0

## Stacks in the network diagram

- **Stacks drawn as stacks:** a stacked switch (VSF, backplane stacking or a Cisco stack) is drawn as its members, each faceplate directly beneath the one before, inside a frame named for the stack (for example "VSF stack · 5 members"). Before, the members were placed side by side, which made the core network page very wide and small.
- **VSF links:** the VSF links from the configuration join the members on their stacking ports (each member's link 2 to the next member's link 1, closing the ring for three or more members), as their own link type in the legend.
- **Links on the right member:** uplinks, downlinks and access points connect to the member that has their port, and devices below the stack are drawn beneath its last member.
- The box style still shows a stack as one box, and the port map pages show each member as before.
