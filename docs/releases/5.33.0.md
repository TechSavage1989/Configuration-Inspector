# Config Inspector 5.33.0

## Visio files open in Microsoft Visio

- **Fix:** network diagram downloads failed to open in Microsoft Visio (error 271, "parts are missing or invalid"). The Visio package now follows Visio's own structure:
  - Document settings are written the way Visio expects.
  - Fonts are named.
  - Each shape's settings come in the required order.
  - The files inside the package carry valid dates.
- **Regression checks:** tests now verify this structure on every build.

## Diagrams fit letter paper

- **Layout:** every network diagram is arranged to fit a standard letter sheet. The app tries several row widths and keeps the one that needs the least shrinking, in landscape or portrait. A VLAN list moves below the diagram, in columns, when that fits better.
- **Label:** next to the title, for example "Letter, landscape, 67%". Very large diagrams are flagged when their text would be small.
- **Downloads:** Visio, SVG and printable downloads are laid out on letter pages. The device library spreads over several letter pages.

## Name and describe your diagrams

- **Document details** on the diagram page sets:
  - Title, subtitle and file name.
  - **Prepared by** and **Organization**, which are remembered.
- They appear on the drawing (title, header, prepared-by line), in the Visio document properties (title, subject, author, company) and in download names.

## Find devices to add or remove

- **Search:** **Add or remove devices** has a search box (name, model or address).
- **Filter:** show all devices, only those on or off the diagram, or a device type.
- **Bulk actions:** **Add shown** and **Remove shown** apply to every device the search shows.

## Vendor stencils

- **Prompt:** until you import vendor stencils, the diagram says devices are drawn as generic faceplates and offers **Import stencils**. When imported stencils match no device shown, it says so.
- **Folders:** **Import a stencil folder** reads every stencil in a folder and its subfolders.
- **Add files:** a Visio drawing (.vsdx) added there is read as a stencil source too.
- **Older stencils (.vss):** stencils from Visio 2003 to 2010, the format many vendors still publish, are read directly. Visio does not need to be installed. Their shapes, artwork and port connection points work like .vssx stencils, and Visio downloads contain the vendor shapes. Stencils from Visio 2002 or earlier are listed so they can be resaved in a newer Visio.

## Navigation

- **Network map** is now **Interface map**, which better describes it: each interface of the open configuration grouped by zone, network and connected device.
- **Site map** has a connected-devices icon that matches what it shows, and Interface map has its own icon.
