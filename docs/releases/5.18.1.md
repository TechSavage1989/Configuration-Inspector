# Config Inspector 5.18.1

- Adopt the supplied editable Configuration Inspector SVG as the canonical icon for the desktop application, browser favicon, in-app branding and release icon download.
- Generate matching PNG and multi-size Windows ICO assets from that source, with build checks preventing stale or mismatched artwork.
- Select the matching small and large native window icons; remove the competing legacy browser favicon.
- Include the portable application ZIP, extraction/runtime instructions and checksums automatically alongside the existing EXE, HTML and SVG downloads.

This is an icon/packaging update. Search, comparison, parsers and update behavior are unchanged. Microsoft Edge WebView2 Evergreen Runtime remains required for the Windows application. The existing 5.18.0 downloads remain unchanged; its separately added portable ZIP contains the original 5.18.0 executable.
