# Config Inspector 5.48.0

## Visio export

- **Fix:** Microsoft Visio still reported error 271 on exported drawings. NetworkDiagramStudio, whose exports open in Visio, repaired the same error by adding parts Visio expects. Visio files now include them:
  - the drawing window settings (`visio/windows.xml`) and their relationship;
  - a recalculation instruction (`docProps/custom.xml`, `RecalcDocument`) and its relationship;
  - explicit default style references, a color table and declared fonts (Calibri, Arial, Segoe UI);
  - line weights in points, with the cached value Visio expects;
  - one Angle cell on every shape, and page line-jump settings.
- Exports pass NetworkDiagramStudio's own package checks (`check-visio-package.py`), and the owner confirmed that drawings with and without vendor stencils now open in Microsoft Visio.
