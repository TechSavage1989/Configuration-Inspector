# Config Inspector 5.28.0

## Network map opens collapsed

- Every group on the **Network map** starts collapsed: port and interface groups, VLAN interfaces, zones and **Connected devices (live)**. So does every interface with subinterfaces. The map opens as a short overview of its groups and counts; click a heading to expand it.
- **Expand all** and **Collapse all** work on every group and nested item, in both the detailed and compact maps.
- Searching the map or filtering by zone opens the groups that contain matches. Clearing the search returns to the collapsed overview.
