# Config Inspector 5.37.0

## Edit the diagram by hand

- **Edit** on the Network diagram toolbar turns on the editor; **Done** turns it off.
- **Move:** drag devices and access points to move them; Shift-click selects several, and dragging moves them together.
- **Links:** drag the middle of a link to move that stretch. Double-click a link to choose the port each end uses on the drawing (configurations and imported data stay as they are).
- **Labels:** double-click any label to change its text; leave it empty to hide it.
- **Alignment tools:** line up selected devices and access points on their left edges, centers or tops, or space them evenly. **Straighten access point links** moves access points over the ports they use, without overlapping.
- **Undo** and **Reset layout**.
- Edits are kept on this computer for each view of the site, and the Visio, SVG and printable downloads include them.

## Aligned by default

- The first device of every row now starts on the same left edge, so stacked devices line up vertically.
