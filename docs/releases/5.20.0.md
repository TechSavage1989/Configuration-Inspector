# Config Inspector 5.20.0

## Recent files

- The start screen lists the configurations you opened recently. Click one to open it again without browsing for it. Available in the desktop app, Microsoft Edge and Google Chrome.
- Only the file name, device name, vendor and file location are remembered, never the configuration itself. The file is read again from its original folder; Windows or the browser may ask once for permission.
- Remove a single entry or use **Clear list**. **Delete stored data** in App settings also clears the list.

## Configuration review

- **Unused objects:** address objects and groups, service objects and groups, IP pools and access lists that no rule, group, interface or other setting refers to. Built-in FortiGate objects are ignored, and anything that might be referenced is treated as used.
- **VLANs used but not defined:** ports assigned to a VLAN that the configuration never declares. VLAN 1 and reserved VLANs are never reported.
- **Defined but unused VLANs:** VLANs with no ports and no VLAN interface.
- **Access ports in VLAN 1** and **trunks that carry every VLAN** are listed as recommendations.
- VLANs declared in a range (for example `vlan 20,30` or `vlan batch 20 30`) are now all recognized as defined.

## Start screen

- The supported formats list now includes Arista EOS, Huawei VRP and MikroTik RouterOS.
