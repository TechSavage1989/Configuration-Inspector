# Config Inspector 5.70.0

## Link checks on the Site overview

A new **Link checks** tab on the Site overview compares both ends of every link between two open configurations. Each finding names the device and port at each end.

- **Native VLAN differs:** the two ends send untagged traffic in different VLANs.
- **Trunk VLANs differ:** a VLAN is tagged on one end only, so it does not pass the link.
- **Trunk or link aggregation on one end only**, and aggregations with a different number of member ports on each side.
- **Spanning-tree root:** no switch sets a bridge priority, several share the lowest one, or the switch that becomes root has fewer links than another.

Links come from imported neighbor data (LLDP / CDP output or a monitoring export) when there is any, otherwise from port descriptions that name the other device.
