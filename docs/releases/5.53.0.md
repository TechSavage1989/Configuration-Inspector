# Config Inspector 5.53.0

## Port modules

- Each SFP or QSFP cage a link uses now shows the module that fits the link type and speed: an SR, LR, ER, ZR, BiDi or WDM optic, a DAC or AOC cable end, or an RJ45 copper module. The diagram legend gains a **Port modules** list that names each module (for example "SFP+ 10G SR fiber optic") with the ports that use it.
- Choose another module, or none, for a link type in its **Link type** dialog (**Port module**), or turn modules off under **Show → Port modules**. Modules are plain shapes, so they come through in the Visio export too.

## Dropdowns and text boxes

- Dropdowns and suggestion lists open a menu in the app's own style instead of the system's dark popup.
- A suggestion list (such as the hardware model or the cable type) shows every choice when you click it, even when the box already holds text, and narrows as you type. The arrow keys, Enter and Escape work as before.
- Text boxes show a **×** button while they hold text, to clear them in one click.

## Updates

- The update screens are redesigned: the installed and new versions shown side by side, a **What's new** card with the release highlights, and an animated download bar showing the amount downloaded and the percentage. The bar turns green while the download is verified.
- **Review and restart** shows the full release notes and lists what happens during the restart.
