# Config Inspector 5.17.1

## Comparison workspace refinements

- Keep Config Text, Config Objects and original fields within the available window
  height. Toolbars remain visible; only result areas scroll.
- Match text loaders to the existing object loader cards. Replace, paste, select
  or drop a file into either side, and clear inputs independently without editing
  source files. Current and Comparison identities remain explicit.
- Collapse input cards into compact filename summaries to reclaim review height;
  preserve mode inputs, object filters and comparison state.
- Group object results under real category headings, including supported DNS/DHCP
  sections. Preserve corresponding left/right objects and field alignment.
- Make wheel scrolling natural over results, cards and spacing. Expanded original
  setting tables scroll locally and chain into results at their boundary.
- Add a compact full-document text change map with colored added/removed/changed
  markers, viewport tracking, click-to-jump and keyboard navigation. The map uses
  bounded rendering and crosses aligned-row pages without losing either input.

Existing diff matching, line numbers, synchronized scrolling, difference navigation,
secret masking, original fields, parser behavior and encrypted updater handoff
remain intact. Direct text remains read-only, UTF-8, at most 5 MB per side, and
requires acknowledgment before displaying unmasked input.

Windows x64 and standalone HTML download names and updater safeguards are unchanged.
