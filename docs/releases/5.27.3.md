# Config Inspector 5.27.3

## Copy live data

- Values from supplementary data can be copied: MAC addresses, IP addresses, ports, device names and other values in every Supplementary data table, the live tabs in Routing, Switching and System & management, the site map device panel and the neighbor details window. Hover a row to see the copy icon, or click the value.
- Each of these tables has a **Copy table** button that copies the rows shown (after any filter) with their column names, ready to paste into a spreadsheet or ticket.
- In an interface's **Live data**, each device seen on the port has copyable MAC and IP addresses, and **Copy all** copies the full list.
