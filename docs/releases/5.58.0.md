# Config Inspector 5.58.0

## Chassis as they are built

- **Real slot grid:** an HPE 5406R or 5412R zl2 is drawn as its front panel. The management modules sit on top (MM1 with its OOBM port, MM2), then the module slots two across (A | B, C | D, E | F, and on to K | L on a 5412R). Empty slots show as dashed blanks. Each card has its slot ring and module model, and the cards sit inside a chassis frame titled with the chassis model. Links land on the module that has their port.
- **Port maps too:** the port map draws the chassis as the same grid, continued on the next page when a 12-slot chassis is too tall.

## Less empty space

- **Tighter rows:** after the links are routed, the space between each row of devices is cut to what its links actually use, as long as no link has to cross more or squeeze in.
- **Thinner bands:** a device side without port labels keeps only a thin band.

## Port maps and trunk VLANs

- **Model beside the name:** each device's, stack member's and chassis's model sits right beside its name on the port map, not at the far edge of the page.
- **Fewer trunk pages:** trunk VLAN tables follow one another on the same page, each under its own heading, instead of each starting a new page.

## Fixes

- **Gateway links:** links guessed from a default gateway no longer reuse a port another link already uses, and no longer pick a port described for other equipment (such as "Channel to storage switches").
