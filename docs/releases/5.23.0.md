# Config Inspector 5.23.0

## Simpler navigation

- The sidebar is organized into **Workspace** (Overview, Device information, Config review, Site overview and Compare configs), the configuration areas found in the export, and **Source & export** (raw configuration, configuration sections, original fields and exports).
- Click a section heading to collapse it. Your choice is remembered on this computer, and the section that holds the page you are on always stays open.
- Hover over a sidebar item to see what the page shows.
- Section headings use one consistent style, and the duplicate section list at the bottom of the sidebar has been removed. Configuration sections remain available from **Source & export**.
- The **Source configuration** bar at the top of each page is now a slim single line, leaving more room for the page itself.

## Network map

- Every group in the network map can be collapsed or expanded from its heading, in both the detailed and compact maps.
- **Collapse all** and **Expand all** buttons open or close every group at once.
