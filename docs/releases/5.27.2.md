# Config Inspector 5.27.2

## Headers stay at the top across the app

- On every page that scrolls as a whole, headers now stay at the top while you scroll. This covers each panel's title row with its search, filter and sort controls, toolbars such as the Network map search and the Config review filters, and table column headings. They stack under each other, so you can always see which column is which and change filters without scrolling back up.
- On the **Supplementary data** page the tab row, the table title with its filter, and the column headings stay at the top together.
- Pages that already scroll their table inside a fixed frame, such as **Interfaces**, **VLANs** and the other configuration sections, keep their toolbar and column headings in place as before.
