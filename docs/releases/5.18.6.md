Adds Cisco WS-C3650-48FD-L support, including FD/PD models with LAN Base, IP Base and IP Services suffixes. Corrects the 3650 front panel to 48 1G RJ45 ports, two 1G SFP slots and two 1G/10G SFP+ slots (G3/TE3 and G4/TE4), with member-specific stack layouts and the four uplinks in one row.

The Model selector accepts the exact FD SKU without changing the imported configuration. Configurations that provision a 48PD retain that source identity and receive the same corrected port layout. Explicit Cisco IOS version banners now retain the full patch release (for example, 16.9.6); a configuration containing only `version 16.9` remains labeled 16.9.
