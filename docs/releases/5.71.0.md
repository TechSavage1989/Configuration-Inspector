# Config Inspector 5.71.0

## A clearer Site map

- **Port tags on the devices:** every link now ends in a small tag on the edge of each device, showing the port (or ports) the link uses on that device. The ports no longer float over the lines, and tags never cover a line, a device or each other.
- **Right-angled links:** links are straight lines with square turns instead of curves that fan out from one point. Each link has its own track, so two links never run on top of each other. A link with several cables is drawn thicker and its tags list each port.
- **See both ends at once:** point at a link (or select it) and the line and both of its port tags light up. Clicking a link still lists every cable with what the imported data says about each port.

## Fewer false cables from monitoring exports

- **VLAN interfaces are not ports:** a neighbor that a monitoring tool reports on a VLAN interface (such as `DEFAULT_VLAN`, or an interface it types as virtual) is no longer drawn as an extra cable beside the real port. When two devices only report each other that way, the two reports are joined into one cable between the real ports; a port known on one side only shows `?` on the other.
- **One cable per port:** a port reported against two interfaces of the same device (for example a firewall interface that is down, listed beside the real one on two switch ports) keeps only the interface that is up and that no other port is also reported against.
- **Stack members are the stack:** a stack member that a monitoring tool lists as its own device ("… Member 2", joined by stack ports) is no longer drawn as a separate switch.
- **Long and placeholder port names:** very long interface names are shortened in the tag (the full name shows when you point at it), and placeholder names such as "Some Interface" show as `?`.
