# Config Inspector 5.17.2

## Comparison navigation

- Add a compact Config Objects section sidebar with real current-page headings,
  click-to-jump bookmarks and an active section that follows result scrolling.
- Make the double arrows between Current and Comparison inputs the **Swap sides**
  button. Remove the separate redundant swap control; retain the same centered
  action when loaders are collapsed, with keyboard access and a hover/focus hint.
  Swapping is read-only and supports empty or partially loaded inputs.
- Make the text change map's viewport draggable, smoothly moving both panes and
  crossing 500-row page boundaries without losing pointer capture. Retain map
  clicks, keyboard navigation, markers, ordinary scroll and difference navigation.
- Add an object change map measured from actual variable-height cards and sections.
  Click markers, drag its viewport or use keyboard navigation. Expansion, resize,
  filters, pagination and input changes refresh its positions automatically.
- Keep object bookmarks and map explicitly scoped to the current results page;
  hidden or paginated-away objects are not represented as directly reachable.

Preserve fixed-height workspaces, collapsible loaders, independent read-only
inputs, object grouping, natural nested scroll handoff, text alignment and all
existing comparison filters. Parsers, settings and updater safeguards are unchanged.

Windows x64 and standalone HTML download names remain unchanged.
