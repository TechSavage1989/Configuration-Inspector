# Config Inspector 5.68.0

## Uses the whole window

- **Every tool fills the screen:** the app no longer stops at a fixed width with empty margins on wide screens; every tool and tab uses the full width of the window, whatever its size.
- **More room for the network diagram:** the diagram view uses a slim heading and file row, keeps the page tabs on one row (scrolling sideways when there are many), slims the title bar and puts the editing tools on one bar. At 2000 x 1054 the drawing area is about 65% taller than before (694 px instead of 421 px); on smaller windows the toolbars stay on one row by hiding the "Device" and "Levels" captions.

## Stacks beside the device they join

- **Links leave sideways:** a link to a stack member can now leave the stack straight out sideways through the gap at its member's height, not only through the stack's top or bottom edge. The app picks whichever way gives the shortest path, so a stack moved beside the chassis or firewall it joins no longer makes its links climb over the stack or drop under it and come back. **Tidy links** uses the same choice.
