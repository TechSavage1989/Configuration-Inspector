# Config Inspector 5.19.1

## Interfaces at a glance

- Port layouts now grow to fill the width of their card. On wide windows each port tile, its icon and its number are larger and easier to read, instead of leaving empty space beside the switch.
- Tiles stop growing at a comfortable maximum, so small devices with only a few ports do not turn into oversized blocks. Narrow windows keep the existing compact fit, and **Enlarge** still shows the full-size layout with horizontal scrolling.
