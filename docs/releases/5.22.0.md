# Config Inspector 5.22.0

## Site overview

- Open two or more configurations from the same site and choose **Site overview** in the sidebar to see them side by side.
- **Settings consistency** compares NTP and DNS servers, DNS domain, syslog and SNMP destinations, SNMP location, local user accounts, time zone and spanning-tree mode across every device, across vendors. The device that differs from the rest is highlighted, and a setting missing from a file is labeled as missing rather than different.
- **VLANs across devices** shows where each VLAN exists and flags VLANs whose names differ.
- **Duplicate IP addresses** lists addresses configured on more than one device, and **Shared subnets** shows which devices have interfaces in the same network.
- **Descriptions naming another device** lists interface descriptions such as "Uplink to CORE-SW1". Saved configurations do not include live neighbor tables, so no physical link is assumed.
- The overview updates as configurations are added or closed, and never shows passwords or keys.
