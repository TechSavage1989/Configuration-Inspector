# Config Inspector 5.74.0

## Signed downloads

- **Code signed:** `Config_Inspector.exe` is now Authenticode signed with Azure Artifact Signing, so Windows and your antivirus can see who published it. Right-click the file, choose **Properties → Digital Signatures** to check the signer. The portable ZIP contains the same signed executable.
- Windows SmartScreen may still show a warning for a little while after a new release, until the signed app builds up reputation.
- Nothing else changes: the app, its settings and the update checks work as before.

Open **App settings → App updates**, or use the update notice in the corner of the window, then choose **Download update** and **Review and restart**.
