Built-in desktop updates and GitHub development releases.

- App settings now includes automatic checks, manual checks, download progress and release notes.
- A compact update notice offers Download, Review update and Later.
- Downloads are verified against GitHub's SHA-256 digest, byte count, product identity, architecture and version.
- Installation preserves preferences, the app data location, the executable filename and open configurations and comparisons.
- The self-contained update helper retains the previous executable and attempts rollback if startup fails.
- Development, Windows builds, regression tests and release publishing now use TechSavage1989/Configuration-Inspector.

Download Config_Inspector.exe for Windows x64. The interface and icon are embedded. Microsoft Edge WebView2 Evergreen Runtime must be installed. The HTML edition and editable SVG icon are also available.

This is the initial version with built-in updates. Earlier versions require a one-time manual download. Future releases can be downloaded and installed from App settings. Builds are not Authenticode signed.
