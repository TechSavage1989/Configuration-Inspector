# Config Inspector 5.43.0

## Visio export

- **Fix:** Microsoft Visio refused exported drawings with error 271. The document now carries its own document ShapeSheet ("TheDoc"), which Visio requires and LibreOffice did not. Text starts with its character and paragraph rows, as Visio writes it, and the drawing no longer names a guide style that does not exist.

## Readable on one sheet

- Port numbers and details on links are larger (12 pt, bold).
- Diagrams fit the area shared by A4 and US letter paper, so a page prints whole on either.
- When a downstream diagram would have to shrink below about 70% to fit a sheet, the first page shows the selected device and its direct neighbors, and each branch with its own devices gets its own page ("<device> and below") in the page tabs and in the Visio, SVG and printable exports.
