# Config Inspector 5.27.0

## Supplementary data where you need it

- **Live tabs in the matching sections:** **Routing** gets **Routing table (live)** and **ARP table (live)**, **Switching** gets **Neighbors (live)** and **MAC address table (live)**, and **System & management** gets **Monitoring data (live)** (model, serial number, software, CPU, memory and alerts). They appear in the sidebar as subsections, and a section appears even when only imported data exists for it.
- **Network map:** each interface shows a live link dot and the neighbor it connects to. A **Connected devices (live)** group lists neighboring firewalls, switches, access points and other devices with the ports on both ends. Map search also finds interfaces by neighbor name.
- **Neighbor details:** click a neighbor on the Network map, in a Neighbors table or in the Supplementary data page to see its hostname, type, model or platform, IP and MAC addresses, capabilities, serial number and software, and every link to the open configuration with the local and remote ports, link state, remote port description and MAC address. From there, open its configuration or show it on the site map.

## Easier scrolling

- The **Supplementary data** page has a row of tabs: **Files**, then one tab per table. Only one table is shown at a time, each with a filter and **Show more**, and the page scrolls as one instead of having scroll areas inside it.
- On the **Site map**, wide maps scroll sideways inside the map and the mouse wheel scrolls the page; the device panel grows with the page.
