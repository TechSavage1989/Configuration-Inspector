# Config Inspector 5.27.4

## Consistent side panels

- The **Site map** device panel now uses the same layout as other side panels such as Device information. It shows a title with the device role, label and value rows for type, model, addresses, serial number and software, and one row per connection: local port ↔ connected device, with the remote port, type and source underneath. Access points and other devices are listed separately under **Attached devices**. The narrow table that stretched text vertically is gone.
- The **Live data** section in interface details now uses the same cards as the rest of the details panel.
- Long device names no longer run under the **Config** marker on site map devices.
