# Config Inspector 5.42.0

## Link types

- **Fix:** changing a link type's color and name in the legend did not change the drawing. It now recolors every link of that type and renames its legend entry.
- **One link, its own type:** right-click a link while editing, choose **Link type, color and name**, and keep **This link only** to give that link its own name and color (for example "10 Gbps SFP+ DAC" in black). It gets its own legend entry, shared by any other link given the same name; Ctrl+Z undoes it.

## Layout

- Access points and other endpoints show their full names; their boxes are as wide as the longest name on the page.
- Endpoints sit over the body of their switch (its ports), not over its label, and a row too wide for the body still stays within the device.
- **Port map:** the faceplates no longer repeat the device's name, model and address beside them (the heading above each faceplate already shows them).

## Stencil port points

- **Fix:** on stencils whose SFP+ cages carry several connection points each (such as a 48-port Aruba CX 6100), ports 1-48 were placed a few columns to the left, starting on the cages. A group of ports may now take several of the stencil's points per port column (split at the widest gaps), so the cages and the RJ45 ports each land on their own points.

## Fixes

- The file search in **Choose a shape** did not filter the stencil files.
- Masters converted from older Visio stencils (.vss) carry the UniqueID and BaseID that Visio's own masters have.
