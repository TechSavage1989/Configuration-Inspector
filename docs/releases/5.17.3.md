# Config Inspector 5.17.3

## Update notices and Help action

- Help → Check for updates now opens the update controls and performs a check, even when no settings dialog is open. Requests during startup are delivered once the interface is ready.
- Automatic checks run shortly after startup and every five minutes while the app is open, respecting the automatic-check setting.
- Later defers only the displayed release for 24 hours; a newer release can appear, and an expired reminder returns without requiring a manual check. Downloads and installation still require your choice.

## Comparison maps and consistent controls

- All three comparison modes now have content-appropriate change maps, including measured original-field rows.
- Press and drag from anywhere on a map—track, marker or viewport—to scroll. Text panes stay synchronized; pointer capture, cancellation and keyboard navigation are retained.
- Config Objects includes neutral unchanged markers when filters include those objects. Sections can be collapsed; bookmarks and collapsed map markers expand the represented section before navigating.
- Collapsed sections use labeled per-state counts at their real heading positions rather than imaginary hidden-card geometry. Object and original-field maps cover the current filtered results page; the text map spans the full aligned comparison.
- The text secrets-visibility control is in the results toolbar, leaving configuration loaders aligned across modes. All modes share the same centered Swap sides design.

Comparisons remain read-only. Existing input limits, bounded text rendering, filters, source preservation, masking, update verification and rollback safeguards are unchanged. No automatic download or restart is introduced.
