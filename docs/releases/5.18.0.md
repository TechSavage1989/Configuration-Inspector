# Config Inspector 5.18.0

## Global configuration search

- Search the active configuration across parsed objects, original fields, native sections, displayed source text and configuration-derived findings, independent of local table filters.
- Use All/Any terms, quoted phrases, excluded terms, Match case, Whole word and section/source/context filters. Regex is intentionally not enabled.
- Inspect all non-overlapping occurrences with bounded result pages and occurrence navigation. Counts explicitly distinguish locations and separate representations of the same source setting.
- Open the relevant object, original field, native section, source line or finding. Return to the search with its state intact, or return to the previous workspace.
- Sensitive values are masked before indexing and counting. Search remains local, read-only and cancellable; replacement and visibility changes invalidate stale results.

Source-text coverage follows the safely retained imported content. Displayed line numbers may refer to normalized text rather than original file lines. Existing comparison loaders, all three comparison modes, maps, scrolling and updater behavior are preserved.
