# Config Inspector 5.59.0

## Pages that fit the drawing

- **Fit to drawing (new default):** the diagram page is now as large as the drawing, at full size, as Visio does by default. Any number of devices fits on one page, and the diagram is never split into "and below" continuation pages. The label next to the title shows the page size in inches.
- **Paper for printing:** Letter, Legal, Tabloid, ANSI C and D, A4, A3 and A2 are still under **Document → Paper** when you want to print on a sheet. A paper size you chose before is kept.
- **Downloads use the page size:** Visio pages, SVG files and the printable page all use each page's own size. Before, SVG files always said 11 × 8.5 in.

## Devices list

- **Two clear lists:** devices **On this diagram**, each with a **×** to remove it, and devices **Not on this diagram**, each with **Add**. The device the diagram is drawn from is marked **Drawn from**.
- **Clear all** removes every device except the one the diagram is drawn from. **Undo added and removed devices** brings them back.
- A stack or chassis counts as one device in the list. Right-clicking a stack member or chassis module on the diagram removes the whole stack or chassis.
