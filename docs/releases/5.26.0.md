# Config Inspector 5.26.0

## Supplementary data and the site map

- **Open monitoring exports and command output** alongside configurations: Auvik site and device reports (.xlsx, or single tables as .csv), CSV neighbor tables, and show command output (`show ip route`, `show interfaces status`, `show ip interface brief`, `show interfaces`, `show lldp neighbors`, `show cdp neighbors`, `show mac address-table`, `show ip arp`, FortiGate routing tables and Linux `ip route`). Use **Add files**, drag them in, or paste command output.
- **Site map:** a new page draws firewalls and switches in tiers with the ports that connect them, counts access points and other devices on the switch they connect to, and opens a device's connections when you click it. Devices with an open configuration are marked **Config**; double-click to open one. Search, zoom and **Show access points** help on large sites.
- **Live data on configuration pages:** the device summary shows links up, neighbors and CPU / memory; ports at a glance show which links are up; the Interfaces table adds Link, Connected to, Speed, Devices seen and Errors; and interface details list the MAC addresses on the port with IP addresses from any imported ARP table.
- **Supplementary data page:** lists imported files and what was recognized, lets you choose which configuration a file applies to, and shows neighbors, interface state, the routing table and ARP table, plus devices past their last support date and known vulnerabilities from site exports.
- Data is matched by hostname or interface address, kept in memory only and never written into a configuration or export.
