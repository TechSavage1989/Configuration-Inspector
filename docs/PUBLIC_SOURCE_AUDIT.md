# Public source data review

The initial GitHub source import was reviewed before publication. The 66 text fixtures are synthetic networking examples or three public NetBox CC0 device model definitions. Their reviewed SHA-256 hashes and origins are recorded in tests/public-fixtures.json.

Device names use examples such as Example firewall, Example-Cisco, Review-Forti and Fundamentals-Junos. Example serials include EXAMPLE-123, EXAMPLE-SYNTHETIC and Q234-EXAM-0001. Network addresses use private, documentation, unspecified or multicast ranges. Public DNS resolver examples are permitted explicitly. An unrelated public-address typo in the specifications fixture was changed to 192.0.2.20.

Credential-looking regression values are explicit markers such as TEST_SECRET_ONLY, RADIUS_TEST_SECRET, WIREGUARD_TEST_SECRET, NEVER_EXPORT_THIS_SECRET and EXAMPLE-SECRET. These deliberately exercise secret redaction and insecure-configuration detection. The standard community name public is used to test known weak SNMP settings. They are not supplied device credentials.

The two PEM files contain public, self-signed example certificates with test.example.test and future.example.test subjects. No private keys are included. The MikroTik binary fixture is generated by the literal-data writer in tests/mikrotik-tests.cjs and is excluded from Git. No supplied configuration backups, private validation results, client exports, screenshots or update credentials are included in the repository.

The only binary source assets are the distributable Microsoft WebView2 loader and the application icon. Microsoft SDK license and notice files are retained. Runtime settings, imported configurations and updater workspaces are never source inputs.

scripts/check-public-source.py verifies the exact reviewed fixture hashes, permitted public addresses, public certificate subjects, excluded backup and validation paths, expected binary asset names and common private-key/token signatures. GitHub's release checks run it before publishing. This is a guard for the reviewed initial corpus; new fixtures require content review and an updated manifest, rather than automatic approval based only on a scanner.
